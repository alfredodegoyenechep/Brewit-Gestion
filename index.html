      Conexión API de Toteat

      Conecta cada cafetería y activa la actualización de ventas y detalle de pagos. Un local sin ventas puede quedar conectado antes de abrir.

      Cómo obtener las credenciales en Toteat

      Con la cuenta del dueño, entra a Configuración → Print Server & API → API Config → Agregar API. Usa el nombre Brewit, versión estable, y habilita /products, /sales y /shiftstatus en Seguridad. Toteat exige seleccionar un canal de origen incluso para consultas. Copia los identificadores y el token de cada local en este formulario.

      Ver instrucciones de Toteat

      La actualización automática funciona mientras el servidor Brewit esté encendido. Toteat entrega órdenes cerradas; las cuentas aún abiertas aparecerán cuando se cierren.

      Compras por API de Toteat

      Usa la cafetería seleccionada en la conexión de arriba. Habilita el permiso /accountingmovements en Toteat; Brewit consulta únicamente compras.

      La actualización requiere que Brewit esté encendido. Se conservan los importes de línea; algunos precios unitarios vienen redondeados. Toteat no entrega usuario, forma de pago, costo negociado ni desglose neto/descuento por línea en esta respuesta.

      Maestros de inventario de Toteat

      La Concepción es la fuente única de los maestros compartidos, incluidos proveedores, para todas las cafeterías. Cada actualización conserva las versiones anteriores.
